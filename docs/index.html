Takeaway

Reasoning hurts on this task at both sizes — the per-step latency cost buys fewer exploration steps and the model already plans well enough without it. The bigger 31B-dense without reasoning gets the highest coverage (63.4%) despite producing fewer total steps than 26B-A4B, suggesting it picks better actions per step. Reasoning-on runs converge to the same ~53.5% ceiling at both sizes — bottlenecked by step budget, not by model capability.
