🏗️Architecture

The agent runs inside Docker — Xvfb + Chromium + xdotool. Each step: take screenshot → send to LLM → parse command → execute → repeat.

1Screenshot via scrot → base64 PNG
2Accessibility tree via CDP → ref IDs for elements
3LLM sees screenshot + a11y tree → outputs shell command
4Agent executes: cua-click, cua-type, cua-pw, cua-cdp-js, etc.
5Loop until cua-done or max steps reached
